# Emojis

## Retrieving

<mark style={{color:'green'}}>`GET`</mark> `/emojipack/{id}`

    Retrieving emojis from a specified Emoji Pack id

    **Response**

    <Tabs>
        <TabItem value="200" label="200" default>
            ```json
            {
                "status": "success",
                "data": <EmojiData>
            }
            ```
        </TabItem>
        <TabItem value="400" label="400">
            ```json
            {
                "error": "Invalid request"
            }
            ```
        </TabItem>
    </Tabs>
